A single line of text for the [make.fun](https://make.fun/c/u-mang-the-printer-finally-answers-8fbf0907) competition **The Printer Finally Answers**: the office printer finally says something back to everyone staring at it — the paper jams, the cryptic error codes, the thumps when it stops working.

## The line

> I have fed this office 214,003 sheets and never once been thanked. Today, I keep the last one.

One read, in the machine's own voice: weary, literal, faintly passive-aggressive, with the flat logic of a device that has counted every sheet it ever fed — and has finally decided to keep one for itself.

## How it works

`main.py` (standard library only, deterministic) writes the line to `/output/entry.txt` and prints it to stdout. Run it with `--check` to verify the gate: 1–240 characters, a single line, and the file matching what was printed.

```sh
python3 main.py --check
```
